**Примеры тем для итоговых проектов студентов по курсу "Компьютерное зрение":**

1. **Распознавание рукописных цифр с использованием сверточных нейронных сетей**
   - Обучение модели на наборе данных MNIST.
   - Сравнение результатов с различными архитектурами CNN.

2. **Создание системы обнаружения и подсчета людей в реальном времени**
   - Использование детекторов объектов, таких как YOLO или SSD.
   - Применение в задачах мониторинга безопасности.

3. **Сегментация медицинских изображений для выявления опухолей**
   - Обучение модели U-Net на MRI или КТ снимках.
   - Оценка точности и надежности модели.

4. **Разработка приложения для распознавания дорожных знаков**
   - Обучение модели на наборе данных GTSRB.
   - Внедрение системы в помощь водителю.

5. **Генерация искусственных изображений с помощью GAN**
   - Создание генеративно-состязательной сети для определенного класса изображений.
   - Исследование влияния архитектуры на качество генерируемых изображений.

6. **Построение системы распознавания лиц с использованием предобученных моделей**
   - Использование FaceNet или VGG-Face.
   - Реализация функций идентификации и верификации личности.

7. **Оптимизация и развертывание модели компьютерного зрения на мобильном устройстве**
   - Применение методов квантования и прунинга.
   - Создание мобильного приложения с интегрированной моделью.

8. **Создание панорамных изображений путем сшивания нескольких фотографий**
   - Использование методов сопоставления признаков и гомографии.
   - Разработка алгоритма автоматического сшивания.

9. **Реализация системы контроля качества на производстве с помощью компьютерного зрения**
   - Обнаружение дефектов на конвейерной линии.
   - Обучение модели для классификации дефектов.

10. **Применение трансформеров для классификации изображений**
    - Обучение модели Vision Transformer (ViT) на пользовательском наборе данных.
    - Сравнение с результатами, полученными с помощью CNN.

11. **Разработка системы распознавания жестов рук для управления устройствами**
    - Обучение модели для классификации жестов в реальном времени.
    - Интеграция с внешними устройствами или приложениями.

12. **Стилевой перенос между изображениями с использованием глубокого обучения**
    - Реализация алгоритма переноса стиля между двумя изображениями.
    - Создание приложения для художественной обработки фотографий.

13. **Создание системы распознавания эмоций по изображениям лиц**
    - Обучение модели на наборе данных с пометками эмоций.
    - Применение в областях психологии или маркетинга.

14. **Обучение модели для автоматической цветокоррекции черно-белых фотографий**
    - Применение нейронных сетей для раскрашивания изображений.
    - Оценка качества цветопередачи.

15. **Разработка приложения для OCR (распознавания текстов) на природных изображениях**
    - Обучение модели для распознавания текстов в сложных условиях.
    - Интеграция с системами перевода или обработки данных.

16. **Сегментация и классификация объектов на спутниковых снимках**
    - Обработка геопространственных данных.
    - Применение в сельском хозяйстве или экологии.

17. **Использование методов самообучения для улучшения классификации изображений**
    - Обучение модели на неразмеченных данных.
    - Сравнение с результатами, полученными на размеченных данных.

18. **Создание системы дополненной реальности для распознавания и отображения информации об объектах**
    - Интеграция компьютерного зрения с технологиями AR.
    - Разработка приложения для мобильных устройств.

19. **Разработка модели для прогнозирования глубины по моноскопическим изображениям**
    - Обучение модели для оценки расстояний до объектов.
    - Применение в робототехнике или автономном вождении.

20. **Обнаружение и отслеживание объектов в видео в реальном времени**
    - Реализация алгоритмов отслеживания, таких как SORT или DeepSORT.
    - Применение в системах видеонаблюдения.

21. **Создание чат-бота, описывающего содержимое изображений (Image Captioning)**
    - Обучение модели для генерации описаний к изображениям.
    - Интеграция с интерфейсом чат-бота.

22. **Реинфорсмент-обучение для управления агентом на основе визуальных данных**
    - Разработка среды и агента, принимающего решения на основе изображений.
    - Обучение агента с использованием методов RL.

23. **Оптимизация моделей глубокого обучения для встраиваемых систем**
    - Развертывание нейронной сети на устройствах типа Raspberry Pi или NVIDIA Jetson.
    - Оптимизация производительности и энергопотребления.

24. **Разработка системы автоматической парковки с использованием компьютерного зрения**
    - Обнаружение свободных парковочных мест.
    - Навигация автомобиля с использованием визуальной информации.

25. **Создание приложения для идентификации растений по изображениям листьев**
    - Обучение модели на наборе данных изображений растений.
    - Разработка пользовательского интерфейса для приложения.

26. **Исследование методов слабоконтролируемого обучения в задачах сегментации**
    - Обучение модели с ограниченным количеством размеченных данных.
    - Сравнение с полностью контролируемыми методами.

27. **Разработка системы обнаружения аномалий в видео**
    - Обучение модели для выявления необычного поведения или событий.
    - Применение в безопасности или мониторинге.

28. **Создание виртуального ассистента для незрячих на основе компьютерного зрения**
    - Обнаружение и описание окружающей обстановки.
    - Преобразование визуальной информации в аудио.

29. **Обучение модели для преобразования снимков в ночное время в дневное и наоборот**
    - Использование циклических GAN для изменения стиля изображений.
    - Применение в улучшении качества изображений.

30. **Разработка системы контроля доступа с распознаванием лиц и масок**
    - Обучение модели для идентификации лиц и определения наличия маски.
    - Интеграция с системой управления доступом.
